Lesson 03 / about 10 minutes

Decode generically. Fail specifically.

A transport service can decode any caller-supplied schema without knowing the domain, as long as each boundary reports the right failure.

Win for this lesson: You will be able to design the error channel of a generic runJson method without collapsing different failures into unknown.

1. Two different parsing failures

FailureExampleEffect error
JSON syntax failure{ "items": CurlJsonError
Schema mismatch{ "items": 42 } when an array is requiredSchemaError

Both are failures, but they carry different information. Syntax failure means the body was not JSON. Schema failure means it was JSON, but not the shape this caller requested.

2. Choose the Effect constructor by the boundary

JSON.parse is synchronous and may throw, so use Effect.try, not Effect.tryPromise:

const parseJson = Effect.fn("CurlService.parseJson")((stdout: string) =>
  Effect.try({
    try: () => JSON.parse(stdout) as unknown,
    catch: (cause) => new CurlJsonError({
      stdout,
      message: "The curl response was not valid JSON.",
      cause
    })
  })
)

The constructor choice communicates what kind of external boundary is involved:

  • Effect.try catches synchronous exceptions.
  • Effect.tryPromise catches Promise rejection and receives an abort signal.
  • Schema.decodeUnknownEffect validates unknown data and returns a typed schema failure.

3. Compose the boundaries

const runJson = Effect.fn("CurlService.runJson")(
  function* (schema, request) {
    const response = yield* attempt(request)
    const json = yield* parseJson(response.stdout)
    return yield* Schema.decodeUnknownEffect(schema)(json)
  }
)

Read the failures from top to bottom:

attempt:   Effect<CurlResponse, CurlProcessError>
parseJson: Effect<unknown, CurlJsonError>

runJson:   Effect<S["Type"],
             CurlProcessError | CurlJsonError | SchemaError,
             S["DecodingServices"]>

Each yield* keeps the success value flowing and unions the failures. This is why typed Effect composition is useful for interface design: the compiler makes the contract accumulate.

4. The schema stays with the caller

// auth.ts
yield* curl.runJson(RawTokenResponseSchema, refreshTokenRequest(credentials))

// spotifyApi.ts
yield* curl.runJson(RawPlaylistsResponseSchema, get(token, playlistsUrl))

The curl service implements the mechanics once. The caller selects the meaning. This is a deep boundary: generic transport below, domain interpretation above.
