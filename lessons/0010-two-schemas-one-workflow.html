Lesson 10 / about 10 minutes

Two schemas, two owners.

The request schema protects the transport boundary. The response schema carries the caller's domain meaning.

Win for this lesson: You will be able to place request and response decoding in the same workflow without confusing their ownership or error meanings.

1. The two schemas

SchemaOwnerWhat it produces
CurlRequestSchemaCurlServiceA trusted internal request with valid method, URL, headers, and form data.
responseSchemaCaller such as AuthServiceThe domain-shaped value the caller wants to use.

The caller supplies a response schema because only the caller knows whether the response should be a token, playlist page, or track page. The curl service owns its request schema because it defines the transport input it can execute.

2. The workflow

const runJson = Effect.fn("CurlService.runJson")(
  function* (responseSchema, encodedRequest) {
    const request = yield* Schema.decodeUnknownEffect(CurlRequestSchema)(
      encodedRequest
    )
    const response = yield* attempt(request)
    const json = yield* parseJson(response.stdout)
    return yield* Schema.decodeUnknownEffect(responseSchema)(json)
  }
)

Read the steps in order:

  1. Decode the transport request.
  2. Execute and classify the process response.
  3. Parse the response body as JSON.
  4. Decode JSON using the caller's response schema.

3. The error channel grows honestly

request decode  -> SchemaError
attempt         -> CurlProcessError
JSON.parse      -> CurlJsonError
response decode -> SchemaError

runJson error = SchemaError
              | CurlProcessError
              | CurlJsonError

Two schema operations can produce the same broad error family while still failing for different reasons. If useful to callers, use context or separate typed errors to distinguish invalid request construction from invalid provider response.

4. What the caller sees

yield* curl.runJson(
  RawTokenResponseSchema,       // response meaning
  refreshTokenRequest(credentials) // encoded request data
)

The caller does not provide CurlRequestSchema. It provides request data and chooses the response meaning.
