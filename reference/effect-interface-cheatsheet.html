Effect Interface Design

A compact guide for reading the curl boundary as a set of contracts rather than one large function.

Read the type

Effect<A, E, R> means: an operation that may succeed with A, fail with E, and require services from R.

attempt(request): Effect<CurlResponse, CurlError, never>

This promises a response or a typed curl error. It does not promise that the process is successful merely because it returned a value.

Sequence, do not nest

CodeMeaning
return valueFinish the generator with a plain success value. If value is an Effect, the success value is itself an Effect.
yield* effectRun the Effect, extract its success value, and propagate its failure and requirements.
Effect.flatMap(effect, next)Explicitly sequence one Effect into another without generator syntax.
 
Effect<Effect<A, E, R>, never, R>  // nested: usually accidental
Effect<A, E, R>                    // sequenced: usually intended

Request model
